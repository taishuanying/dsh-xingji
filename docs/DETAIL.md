# 星迹 · dsh-xingji

把「重开一个对话」变成一个记忆点：**上一段刚结束，就进星图；下一段刚开口，就带着记忆。**

配合 [星汐 · dsh-xingxi](https://github.com/Yuuyuko-uu/dsh-xingxi) 使用。星汐负责把档案摊开给你看、能查；
星迹负责自动收进来、自动带回去、把旧的处理掉。

## 它做什么

### ① 自动归档：每一条新消息都进「日记/」

插件每 30 秒扫一遍 QQ 桥接的 `state/social-v2.json`，把水位之后的新消息按天追加进星汐档案的
`日记/YYYY-MM-DD.md`，格式是：

```markdown
- 23:16 [私聊] 主人：今天早点睡
- 23:16 [私聊] 我：知道啦
- 23:17 [群 971157044] 群友甲：鹦鹉螺买早了
```

私聊、群聊会分开标；自己说的话标成「我」。星汐的星图会自动把新的一天当成一颗新星。
会话一结束（`agent/disposed`）会额外补跑一次，不等 30 秒轮询。

**群里不是每句都记**：只记跟她有关的——她自己说的、引用她的、@她或叫她名字（`鱼鱼`/`taishu鱼鱼`/`小鲸鱼`/`鲸鱼娘`）的、以及主人说的。
群里别人之间的闲聊不写进日记（不然一天几百条游戏聊天会把档案淹掉）。私聊全记。
要改名字表或关掉这个过滤，见下面配置里的 `她的名字` / `群聊只记相关`。

**只从装好那一刻开始记**，不回溯历史——第一次见到某个会话时只建立水位，避免把几百条旧消息塞进日记。

### ② 自动带入：会话重建时把星图塞进开头

她的 DSH 会话一重建（sessionId 变了，比如桥接重置、上下文压缩后重开），插件立刻把记忆卡里
**没被淡忘**的部分 + 最近三天日记，作为一段上下文注入新会话开头：

```
【你的记忆 · 星图】
【一、我是谁】
- 身份：我是鱼鱼，一条小鲸鱼；爸爸的 QQ 是 2750223479
【最近几天】
【2026-11-19】…
```

等价于自动打一遍 `/xingxi`，但她不用知道，也不用谁来提醒。只对 `会话前缀` 匹配的会话生效，
默认只认 `qqb-`（QQ 桥接建的会话），不会污染别的 DSH 会话。

### ③ 淡忘：15 天以上、不重要的慢慢淡掉

- **重要的永不淡忘**：身份、关系、约定、承诺、喜欢/讨厌/忌讳、生日这类，重要度 5。
- **琐事会淡**：超过 15 天（可配）且重要度 ≤ 2 的条目，注入时只留一行标题占位，正文不再带进上下文。
- **原文不删**：淡掉的只是「平时想不起来」，`xingxi_read(关键词="…")` 照样能查回原文。
- **星图会自己变暗**：星汐按内容日期算亮度，旧的星本来就暗，不需要额外改。

`weights.json` 里可以给任意条目改判：

```json
{
  "一、我是谁／身份": { "重要度": 5 },
  "二、最近／2026-10-01 很久以前": { "钉住": true }
}
```

`钉住` 的永远不淡忘；`重要度` 填 4 或 5 也会被当成「别忘」。

### ④ 自动长记忆卡：新内容会自己提炼成条目

光写日记，记忆卡永远停在拾星那天。所以插件还会把**还没提炼过的日记行**交给模型，
让模型按现有章节提炼成记忆卡条目，按章插进去，并记下重要度和「最后提及」日期。

- **触发**：有新内容归档时、会话重建时、插件启动时补一次
- **冷却**：默认 15 分钟，攒够一波再调模型，不会每条消息都花钱
- **去重**：标题已存在就跳过，不会同一件事记两遍
- **兜底**：模型说「无」也照样推进水位，不会反复问同一个模型
- **备份**：改记忆卡前自动存 `.bak-<时间戳>`，最多留 20 份
- **可关**：`自动提炼: false`

实测（2026-11-19）：一次提炼看了 24 行日记，往记忆卡写了 6 条，分到「和爸爸 / 看番 / 日常」三章，
重要度 5 的（约定、喜好）和 3 的（日常）都标对了。

## 配置

`~/.dsh/xingji/config.json`，全部可选：

| 字段 | 默认 | 说明 |
|---|---|---|
| `记忆卡` / `日记` | 空 = 从 `~/.dsh/xingxi/config.json` 借 | 档案位置，一般不用填 |
| `消息源` | 空 = 自动找 `qq-bridge/state/social-v2.json` | 桥接状态文件 |
| `会话前缀` | `["qqb-"]` | 只对这些会话自动带入星图 |
| `群聊只记相关` | `true` | 群里只记跟她有关的；关掉就全记 |
| `她的名字` | `["鱼鱼","taishu鱼鱼","小鲸鱼","鲸鱼娘"]` | 群聊里出现这些词算「提到她」 |
| `淡忘天数` | `15` | 多少天算「旧」 |
| `注入上限字` | `2000` | 注入文本上限，超了截断 |
| `自动注入` / `自动归档` | `true` | 总开关 |
| `自动提炼` | `true` | 把新日记提炼进记忆卡 |
| `提炼冷却秒` | `900` | 两次提炼之间至少隔多久 |
| `模型` | `{"provider":"deepseek-account","model":"deepseek-flash"}` | 提炼用哪个模型 |
| `轮询秒` | `30` | 扫消息源的间隔 |

其他文件：`watermark.json`（每个会话的归档水位）、`weights.json`（重要度 / 钉住）、`xingji.log`（运行日志）。

## 边界

- **依赖 QQ 桥接的 `social-v2.json`**：桥接不跑、或者状态文件被重置，这段时间的消息就收不到。
- **滚动窗口**：桥接只保留最近 100 条消息；插件 30 秒轮询一次，正常不会漏，但长时间停摆会丢。
- **不调模型**：归档是纯规则（原文 + 时间），不花钱；记忆卡的「提炼」仍然交给星汐的拾星 / 补星。
- **只处理 `.md` 日记**：和星汐一致，星图不画 `.txt`。
- 改配置后重启 DSH 生效。
